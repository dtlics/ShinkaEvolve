## 1. CONTROL FLOW

`orchestrator/harness/run_window.py` is the only file that sequences the inner loop; it imports the `orchestrator/scripts/*` policies as modules (run_window.py:53–71) and is invoked as one subprocess per cluster. It is strictly **sequential** — one candidate at a time; every stage below blocks on the previous one's return.

**Boot (per process).** `main()` asserts `shinka` resolves to this worktree (`_common.assert_worktree_shinka`, run_window.py:1233; _common.py:48), asserts the journal discovery-gate helpers exist (run_window.py:1240–1253), refuses to start if `task.task_sys_msg` is unset/`__UNSET_AUTHOR_AT_BOOT__` unless `task.require_sys_msg:false` (run_window.py:1263–1272), clears a stale `.stop` (run_window.py:1290), bootstraps the seed program as gen 0 if the archive has no live rows (`_bootstrap_initial`, run_window.py:266–337 — evaluates `init_program_path`, embeds it when novelty is on, records via `archive_record`), then `journal.init_run` (run_window.py:1293). The CLI path additionally takes the exclusive OS lock `<results_dir>/.run.lock` (run_window.py:2128, `acquire_run_lock`:1856) and self-caffeinates (run_window.py:2073, 1750). The persistent `meta_failure_note` is re-hydrated from the last logged meta call (run_window.py:1305–1308).

**One step (`_run_one_candidate`, run_window.py:545–1227).** Per-gen seed = `evo.seed + generation` (run_window.py:557).

1. **Patch-mode draw before parent**: `_sample_patch_mode` draws diff/full/cross/fix by `patch_type_probs` (run_window.py:592, defaults `["diff","full","cross","fix"]`/`[0.55,0.3,0.1,0.05]`:358–359). A "fix" draw — or the repair latch (prior window's `errored_fraction ≥ repair_trigger_fraction` 0.20, first slot only, run_window.py:1368–1371, 1388) — requests an **errored** parent.
2. **Parent sampling** (MUTABLE `sample_parent.py`): reads the archive via `ProgramDatabase.get_all_programs` read-only (sample_parent.py:196–199). Repair mode picks the newest errored non-tombstoned parent under `repair_attempt_cap` (default 2) with no inspirations (sample_parent.py:207–226). Normal mode: island pick per `db_config.island_selection_strategy` (default uniform, :118–148), same-island pool if `enforce_island_separation` (default true, :292), sigmoid-weighted draw porting `WeightedSamplingStrategy` (`parent_selection_lambda` default 10.0, :309–313), optional `parent_id` pin for combine-grounding (:269). Inspirations are **direction-oriented** when the island has a structured meta brief (sample one weighted direction, use its `assigned_program_ids`, :333–347); pre-brief falls back to top-k+elites or random per `prebrief_inspiration_mode` (:349–367). Empty archive ⇒ auto re-seed and retry once (run_window.py:599–606). Parent + inspiration codes fetched via `archive_query` (embeddings only for cross, run_window.py:624–661).
3. **Prompt** (MUTABLE `construct_mutation_prompt.py`): delegates template-filling to shinka's `PromptSampler` (construct_mutation_prompt.py:72); carries island brief / sampled direction, always-on `failure_note`, `objective_brief`, `extra_guidance`, runtime-budget caution (run_window.py:721–750). Fix branch builds the repair prompt from the parent's own `stderr_log`/`text_feedback` (run_window.py:663–689).
4. **LLM selection** (MUTABLE `select_llm.py`): wraps shinka's `AsymmetricUCB` with state in `<results_dir>/bandit_state.pkl` (run_window.py:762–776; select_llm.py:52–73). Arm ids may be `"model@effort"`, split by `_parse_arm` (run_window.py:340–350). Levers: `force_explore`, `llm_subset`. Per-window `arm_submitted` counters feed the rollback bandit-collapse check (run_window.py:787–789). Repair-escalation override (`repair_escalation_model`, default null) swaps the model on the last pre-tombstone attempt without crediting the bandit (`_escalated`, run_window.py:797–804).
5. **Mutate** (`mutate.py` — body IMMUTABLE, prompt mutable): Azure **background-poll** transport `_azure.bg_query` for azure/openai providers (mutate.py:229–252), retrying **apply failures** up to `max_patch_attempts` (default 3); "fix"/"full"/"cross" route to `apply_full_patch`, "diff" to `apply_diff_patch` (mutate.py:91–103). Cost booked to `counters["cost"]` immediately (run_window.py:847–848); full prompt+response logged to `journal/llm_content/` when `log_llm_content` (default true, run_window.py:850–863). `applied:false` after retries ⇒ cost-only bandit feed, nothing archived, slot dropped (run_window.py:876–891).
6. **Novelty embed (deferred gate)**: embed the parent→candidate **diff** (`novelty_embed_mode:"diff"` default, run_window.py:136–158) via shinka's `EmbeddingClient` (run_window.py:113); accept/reject deferred until after eval (run_window.py:896–912).
7. **Evaluate** (IMMUTABLE `evaluate.py`): shinka `JobScheduler`+`LocalJobConfig`; `scheduler.run()` is deliberately bypassed (it monitors without the timeout — design note evaluate.py:90–94) in favor of `submit_async` then `monitor` **with** the timeout (evaluate.py:123–134); results_dir wiped pre-eval against stale metrics (evaluate.py:108–121). Blocks up to `task.eval_time`.
8. **Immediate fix rounds** (`_attempt_immediate_fixes`, run_window.py:397–542): on eval failure, up to `evo.fix_retry_budget` (default **1**, run_window.py:930–938) re-prompts of the **same arm** with the error fed back, each re-evaluated; budget railguard checked before each attempt (run_window.py:454); error history accumulated; code re-embedded if the fix changed it (run_window.py:948–957). Failure classified timeout vs wrong-answer (run_window.py:966–969).
9. **Repair-gen failure path**: a failed repair archives **no child**; the error is appended to the errored parent via `repair_record.py` (`db.append_program_error`), tombstoning it at `repair_attempt_cap` (run_window.py:988–1011; repair_record.py:56–71); cost-only bandit feed.
10. **Keep-the-better novelty resolve** (run_window.py:1017–1125): `novelty_check.py` computes max cosine vs the (island-scoped by default) archive with threshold `code_embed_sim_threshold` 0.99 (novelty_check.py:59–70). A correct near-dup competes **by score**: worse newcomer dropped (cost-only or `reward_on_reject:"penalize"` bandit feed, run_window.py:1084–1099); better/equal-within-`novelty_tie_epsilon` (default 0.0) newcomer kept and the incumbent tombstoned `reason="novelty_evict"` (run_window.py:1100–1125). Each decision logged to `journal/novelty.jsonl` (run_window.py:1035–1052).
11. **Reward** (MUTABLE `compute_reward.py`): default `mode:"absolute"` — reward = `baseline + max(delta, reward_validity_floor=0.001)` with sign-aware baseline `max(parent,0)`; incorrect/non-finite ⇒ `reward:None` (bandit imputes worst) (compute_reward.py:53–97). Repair gens baseline against the nearest **correct ancestor** (run_window.py:1127–1139).
12. **Record policy** (MUTABLE `record_policy.py`): derived signals into the free-form `metadata` blob only, never the schema (record_policy.py:43–86).
13. **Archive** (IMMUTABLE `archive_record.py`): builds a shinka `Program` and calls `ProgramDatabase.add` (island assignment, elite archive, deferred migration) into `programs.sqlite` (archive_record.py:63–80; run_window.py:1183–1209); still-incorrect entries keep the whole ~8KB-capped `error_history` (run_window.py:1172–1182).
14. **Bandit update** (run_window.py:1217–1227): reward/baseline/cost fed to the arm (skipped when escalated).

**Window wrap-up (`_one_window`, run_window.py:1334–1622).** Loops `window_size` (default 10) candidates with a hard budget railguard before each (run_window.py:1383–1386) and a cooperative `.stop` check between candidates (run_window.py:1394); `.window_active` sentinel guards state snapshots (run_window.py:1376). Then: optional `island_policy.py` spawn/migrate decision (`island_policy_driven`, default off, run_window.py:1411–1435), read-only bandit posterior peek (run_window.py:1440–1455), `diagnostics.py` (IMMUTABLE sensor) which embeds the MUTABLE `stagnation_detector.py` — J = Δ/√W; low window when Δ ≤ max(`stagnation_abs_floor` 1e-3, `stagnation_rel_frac` 0.05 × max(s_start, 0)); stagnation at `consecutive_required` 2 consecutive lows (stagnation_detector.py:62–100) — `journal.append_window` (folds window cost into the ledger, run_window.py:1514), then the **automatic per-window meta round** (`auto_meta` default true, skipped on cooperative stop): one `meta_summarize.py` Azure call (default `azure-gpt-5.5`@medium) reading the full archive + best code, returning a `failure_note` + per-island direction lists auto-recorded as briefs via `island_brief.py`, with hallucinated-island filtering and `meta_health` reporting (run_window.py:1526–1617). Fresh strategy fingerprint zeroes `prior_low_streak` for a fair trial (run_window.py:1320–1332).

**Cluster loop (`--until-decision`, run_window.py:1629–1728).** Before looping: harness-decided termination when `journal.termination_streak ≥ cadence.termination_streak` (default 5) ⇒ finalize `stagnation_intervention_exhausted` (run_window.py:1650–1661). Then windows repeat until: budget hit (finalize `budget_exhausted`, run_window.py:1680–1689, 1734), cooperative stop, or FOUNDATION `cadence_policy.py` says return — immediate on stagnation; every window for the first `early_phase_windows` (5); else uncapped work-score taper `base_low·2^max(0, low_streak−1−early_phase_windows)` (cadence_policy.py:66–106). CLI modes: `--warmup` (throwaway `<results_dir>/warmup`, trace on, `warmup.iters` default 3, run_window.py:2135–2155), `--accept-warmup` (sqlite-backup fold-in + spend as intervention, run_window.py:1974–2047), `--trace-steps`, `--resume` (window_state from journal, run_window.py:2171–2183).
